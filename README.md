## System Description
- Hệ thống sử dụng JS Vanilla để render.
- JS sẽ Fetch data JSON từ folder data ra và render ra HTML. Các module render sẽ được load vào 1 file chính và được gọi ở index.html.
- Style: Màu sắc sử dụng là Dark Mode Cyan ( Màu chủ đạo là xanh neon, background nền đen).
- Project được lưu trữ code ở Github và Deploy ở Vercel.
